## About the Design Files

このバンドルに含まれる HTML/JSX ファイルは、**あくまでデザインリファレンス**
です。プロトタイプとして意図的な見た目・情報構造・振る舞いを提示する目的で
作られたものであり、そのままプロダクションに投入するコードではありません。

実装タスクは、これらの HTML デザインを、
**ターゲット・コードベースの既存環境（React/Vue/Next.js/Nuxt/SwiftUI/Flutter 等）
の中で、そこで確立されたパターンとライブラリを使って再現すること** です。

コードベースがまだ存在しない場合は、プロジェクトに最も適したフレームワークを
選定し、そこで実装してください（推奨は Next.js + TypeScript、CMSは Payload/Strapi/
自前のヘッドレスなど、要件に応じて）。

## Fidelity

**Low-fidelity ワイヤーフレーム** です。以下の点にご留意ください:

- **情報設計・レイアウト構造・コンポーネント分割の意図** は、忠実に再現してください。
- **配色は基本モノクロ寄り** で、テニスコートグリーン `#2f5d3f` と
  クレーテラコッタ `#c4623a` の2色のみアクセントに使っています。
  本実装時はブランドガイドに沿った本番カラーパレットに置き換えて構いません。
- **画像は斜線ハッチのプレースホルダ**（`background: repeating-linear-gradient(...)`）
  になっています。本実装では実素材（Getty Images、ブランド提供素材、撮影素材）に置換します。
- **アイコンはシンプルな線画 SVG** を直書きしていますが、
  本実装ではプロジェクトのアイコンライブラリ（lucide, heroicons, phosphor, Material Symbols 等）
  に差し替えて構いません。
- **タイポグラフィのウェイト・階層・行間・字間** はワイヤーフレーム段階でも
  最終形に近い設計にしてあります。可能な限り準拠してください。

つまり **「レイアウト・情報構造・振る舞い」は hifi 相当、「ビジュアル装飾」は lofi** です。

## Screens / Views

### 共通レイアウト

すべての画面で以下のスマホフレームを共通で使用します:

- **サイズ**: `width: 375px`, `height: 812px`（iPhone 標準相当）
- **ステータスバー**: 高さ 28px、時刻表示 + 電波/バッテリー抽象化
- **AppBar (上部ヘッダ)**: 高さ 44px
  - 記事詳細用: 戻る + ロゴ + 検索 + more (SP的な軽量版)
  - TOP用: メニュー + ロゴ + 検索 + ベル + ユーザー
  - CMS用: 暗色背景 (`#1a1a18`)、戻る + パンくず + 下書き保存 + 公開ボタン
- **タブバー (下部)**: 5アイコン、`grid-template-columns: repeat(5, 1fr)`
  - アイコン: ホーム / ニュース / ツアー / 保存 / マイページ

### ロゴ

- 文字ロゴ `TENNISpress`
  - `TENNIS` はテニスコートグリーン `#2f5d3f`、`press` は黒 `#0f0f0f`
  - font-family: Inter, weight: 800, size: 15px, letter-spacing: -0.02em

- 3つのカードを縦積み:

  - 上部: 商品画像 60×60 + ブランド名 + 商品名
  - 下部: `grid-template-columns: repeat(4, 1fr)` で4スペック (重量/スピン/パワー/コントロール)
    - **各項目の最高値のセルは `--wf-clay-soft` 背景 + テラコッタ文字 + `★` マーク**
- レビュワーが単純に表を眺めるだけでなく、「どこが他より優れているか」がひと目で把握できるのが狙い。

## Interactions & Behavior

**現段階は静的モックのため、実装時に以下の振る舞いを想定して構築してください。**

### 共通
- タブバーの各アイコンタップで対応セクションへ遷移
- パンくずの各ラベルはタップ可能でナビゲート
- 記事詳細のヘッダの `保存` / `シェア` ボタンは、それぞれブックマーク保存とネイティブシェアシート起動

### ツアー速報
- LIVE 中はスコアボードを WebSocket / SSE / ポーリングでリアルタイム更新
- LIVEバッジのパルスアニメ: `@keyframes wfPulse { 0%,100%{opacity:1} 50%{opacity:0.3} }` を 1.8s infinite
- 試合終了後は LIVE バッジを FINAL バッジ (グレー) に置換

### ギア
- 比較表の「差分ハイライト」は、選択商品リストから自動計算:
  - 数値項目は max を、5段階評価は max を取る
  - 本モデル (レビュー対象) は常に緑枠でハイライト
- 固定購入CTAはスクロール中も常時表示（`position: fixed` またはスクロール監視で表示切替）
- CTAボタン押下でECサイトへ遷移 (外部ドメイン、`target="_blank"` + `rel="noopener"`)

### レッスン
- 目次の各項目タップでその見出しへスムーススクロール
- FAQ のシェブロンタップでアコーディオン開閉
- 連続写真は将来的にライトボックス / 縦スワイプで詳細確認できると尚可

### CMS
- ブロックのドラッグハンドルで並び替え (dnd-kit などのライブラリ推奨)
- ブロック追加ツールバーからのタップで該当ブロックを挿入
- **スプシ貼付**:
  - PASTE ZONE で `onPaste` を捕捉
  - `text/plain` の clipboard を取得し、タブ・改行でパース
  - 2列以上の場合はキー・値の表として自動レンダリング
  - パース成功時に緑チェックの成功メッセージを表示
- **タイアップフラグ ON/OFF**:
  - ON時、記事詳細ページのレンダリング時に広告スロット (AdSense / GAM / 自社バナー) を全て非表示にする
  - 記事上部に自動で `PR` ラベルを挿入
- **カスタムCSS**:
  - `<script>` 系タグ、`javascript:` プロトコル、`@import`、`expression()` 等は必ずサニタイズ
  - スコープを記事本文の CSS カスケードレイヤーまたは iframe / Shadow DOM で完全隔離推奨
  - 例: CSS を `@layer article-custom {...}` でラップ、または `<style scoped>`
- **特集への紐付け**:
  - 既存の特集タグは autocomplete で選択
  - `+ 特集を追加` から新規特集を作成できる（モーダルで名称・スラッグ入力）
  - 公開時にバックエンドで特集ページに記事を自動追加
- **プレビュー / SP モード切替**:
  - プレビューモード: 編集チップを外した記事表示
  - SP モード: 375px ビューポートで記事詳細を表示
- **自動保存**: 30秒間隔でドラフトを PATCH。ステータスに `自動保存 · Nミリ秒前` を表示

### ニュース詳細
- 関連ギア／レッスン枠は、記事の選手タグ・カテゴリ・本文 NER (Named Entity Recognition) の
  結果からバックエンドで自動抽出しレコメンド
- CMS側での手動オーバーライドも可能（このIAでは未描写、将来拡張）

- スマホフレーム (`Phone` コンポーネント) は開発中のプレビュー用。本実装ではレスポンシブに置き換え。

- 画像プレースホルダ (`ImgPh`) は `<img>` タグ + 実素材に差し替え。
- アイコン (`Ico.*`) はアイコンライブラリのコンポーネントに置換。
- CSS 変数はそのまま使うか、Tailwind / CSS-in-JS の theme に移植。
- CMS のブロックエディタは、既存の OSS (TipTap, EditorJS, Plate, Lexical, Novel) を使うと工数削減できます。専用ブロック (SPEC-TABLE, COMPARE, STICKY-CTA) はカスタムノードとして実装。
